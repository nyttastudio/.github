# Nytta Studio

**Small, useful apps for Mac and iPhone.**

Independent app studio based in Tokyo, Japan.
*Nytta* is Swedish for usefulness — that's the whole idea: apps that quietly
make everyday work on your devices a little easier.

EN · 한국어 · 日本語

## Apps

### [Araso](https://github.com/nyttastudio/araso) — Type as it flows

Type everything on QWERTY. Araso decides per word whether it's English,
Korean or Japanese, so you never reach for the language key.

Free and open source (MIT) · macOS 13+ · Windows 10/11 beta
→ [nyttastudio.com/araso](https://nyttastudio.com/araso/)
